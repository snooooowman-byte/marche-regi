# マルシェレジ

マルシェなどで使う、決済をしないレジ代わりのページ。タブレット（iPad・Android）のブラウザで開き、ホーム画面に追加して使う。

- メニューのボタンを押すと金額を足す。電卓・値引き・お預かりとお釣りがある。
- メニューは「メニュー編集」を長押しして、追加・削除・値段の変更をする。
- 見た目は右上のボタンで「屋外・ナチュラル・黒板」に切り替える。
- 一度開けば、電波がなくても使える。
- メニューと会計の中身は、そのタブレットの中にだけ保存する。どこにも送らない。
